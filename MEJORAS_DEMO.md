# Conversión a Hotel Ancla

La interfaz y la base de datos fueron reorientadas al dominio hotelero. La versión demo incluye panel, reservaciones, recepción, habitaciones, huéspedes, canales y reportes, además de modelos Prisma para habitaciones, huéspedes, canales y reservas.

La infraestructura fiscal, de autenticación, multiempresa y soporte CoreStack se conserva como base técnica. Los módulos comerciales heredados permanecen disponibles únicamente como infraestructura transitoria mientras se completa su sustitución backend por servicios hoteleros.
